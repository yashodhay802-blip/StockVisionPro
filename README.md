# StockVision Pro: Stock Market Performance Analysis Dashboard

An AI-powered stock market analysis platform built with Python, Flask and machine learning. It provides stock market dashboards, interactive charts, market news, watchlists, paper trading, portfolio tracking and stock price prediction.

## Features

- Stock market dashboards and interactive charts
- Market news
- Watchlist, paper trading and portfolio tracking
- Price prediction using a Random Forest machine learning model
- Technical indicators used: MA20, MA50, RSI, MACD and Volume
- Prediction output: current price, predicted price, expected change, confidence, market trend, BUY/SELL signal and risk level

## Tech Stack

- Language: Python, JavaScript
- Backend: Flask, SQLAlchemy, SQLite
- Machine Learning: Random Forest (scikit-learn)
- Visualisation: Plotly, TradingView Lightweight Charts
- Frontend: HTML, CSS, Bootstrap

## How to Run

1. Install the dependencies: pip install -r requirements.txt
2. Run the app: python app.py
3. Open http://127.0.0.1:5000 in your browser
